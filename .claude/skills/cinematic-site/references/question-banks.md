# Worked question banks

Ten fully-worked archetype banks, one per brief. **These are calibration examples, not a
lookup table.** Read them to see how specific a question should be, then derive your own
for whatever subject you're handed — including for these subjects, when the user's
description diverges from the brief.

What every question below has in common: a different answer **changes what gets
generated**, not just what gets styled.

---

### espresso
- Machine aesthetic: vintage lever / polished chrome commercial / matte prosumer / hand-built brass
- Cup vessel: thick ceramic tulip / clear glass demitasse / stoneware / paper takeaway
- Ending: straight espresso crema close-up / rosetta poured in / cup lifted from counter
- Bean story to surface: single-origin named farm / seasonal blend / roast-to-order
- Business shape: beans by the bag / subscription / physical café / all three

### lip-gloss
- Finish: high-shine wet-look / satin / glitter-flecked / sheer tint
- Hero shade name and family (offer 3 invented names per family: nude / berry / clear / bronze)
- Tube: frosted acrylic / clear glass with metal cap / squeeze tube / magnetic click-shut
- Applicator: doe-foot / tapered wand / sponge tip / rollerball
- The dune-reveal colour — the shade the opening landscape is made of
- Shade range size (sets how many product images you generate)

### perfume
- Bottle silhouette: classical flacon / heavy cylinder / faceted decanter / apothecary square
- Cap: turned wood / brushed gold / solid glass weight / lacquered black
- The actual note pyramid — top / heart / base (drives all three scene generations)
- Concentration and size: EDT 50ml / EDP 50ml / EDP 100ml / extrait 30ml
- Label typography: high-contrast serif / deco geometric / minimal sans / engraved script
- Final beat: bottle alone, or the spray plume freezing

### forged-knife
- Blade profile: gyuto / santoku / western chef's / nakiri / cleaver
- Steel and surface: damascus pattern / kurouchi black forge finish / mirror-polished carbon / stainless clad
- Handle: octagonal ho wood / stabilised burl / black micarta / brass-bolstered
- Maker story: solo smith / small workshop / multi-generation forge — changes the copy voice entirely
- Final cut: tomato / herbs / fish / onion (this is the last frame — choose deliberately)
- Tier: single knife hero / 3-knife set / full roll

### ev
- Class: executive sedan / compact SUV / hypercar / pickup
- Paint: satin unpainted-metal / deep gloss black / single bold colour / raw brushed aluminium
- Headlight signature (the ignition beat depends on it): continuous bar / split matrix / hidden-until-lit
- Show interior? (adds a whole generation) cabin reveal / exterior only
- Specs to surface: range + 0–60 + charge / range only / no numbers, pure design
- Action: reserve with deposit / configure / waitlist

### vinyl
- Genre and era: 60s modal jazz / 70s dub / 80s post-punk / contemporary ambient
- Label design language: Blue Note / ECM minimal / Factory industrial / hand-stamped white label
- Disc: standard black / marbled colour / clear / picture disc
- Business shape: one album release / a reissue label / a pressing service for artists
- Sleeve art direction: abstract / photographic / typographic
- Scroll indicator styled as a track timecode? (recommended — it closes the metaphor)

### botanical-serum
- Hero botanical (drives the entire growth sequence): sea buckthorn / rosehip / centella / prickly pear / bakuchiol
- Bottle: amber glass dropper / frosted white pump / clear glass with wood cap / airless tube
- Texture shown: clear oil / gel / milky emulsion
- Claim focus: barrier repair / brightening / calming / firming — pick one, resist stacking
- Ingredient display: full INCI / 5-ingredient highlight / none
- Skin at the end: forearm / shoulder / collarbone (never a face — models render it uncanny)

### keyboard
- Layout: 60% / 65% / 75% / TKL / full-size
- Case: anodised aluminium / brass / frosted acrylic / walnut / polycarbonate
- Switch family and feel: linear / tactile / clicky, plus a named switch if they have one
- Keycap profile and colourway: cream-on-grey / all-black / retro beige-and-red / two-tone
- Sold as: assembled / barebones kit / group buy with a close date
- Does the actuation beat go inside the housing? (recommended — it is the hero shot)

### spirits
- Category: single malt / aged rum / mezcal / cognac / rye
- Age or provenance: 12 / 18 / NAS with a cask story / single-cask numbered
- Bottle and label: heavy squat glass with letterpress / tall dark glass / wax-dipped / ceramic
- Glassware for the reveal: Glencairn / heavy rocks tumbler / coupe / copita
- Final serve: neat / over the clear ice sphere / a cocktail built on screen
- ABV, size, price — and whether an age-gate interstitial is required for the target market

### satellite
- The actual service: consumer broadband / IoT backhaul / earth imaging / maritime
- Constellation scale: single demo satellite / 12 / hundreds — changes the pull-back beat
- Audience: enterprise procurement / government / consumer subscription
- Ground hardware shown: dish terminal / handheld / embedded module / none
- Specs to surface: latency + throughput + coverage / coverage map only / none
- Ending on the phone in a hand (recommended) or on orbit

## Deriving a new bank — worked example

**Prompt:** *"a very high-quality metal credit card like an AMEX black and gold, with nice
visuals and offer brochure"*

No brief matches. Walk the five dimensions:

- **Materials & finish** → Card finish: brushed titanium / PVD matte black with milled
  gold edge / two-tone anodised / blasted stainless
- **Transformation physics** → Where does the story start: molten pour → precision milling
  → PVD coating → finished card, or start at the machined blank?
- **The hero moment** → Milling swarf peeling off the blank under coolant, or the PVD
  coating flooding across the surface?
- **The ending frame** → Card landing flat on dark stone with the gold edge catching a
  single light, or handed across a counter?
- **Business shape** → Single invitation-only tier, or three tiers with a benefits
  brochure? Does the brochure fold out on scroll?

That's a strong site — physically it's the `forged-knife` brief's material-state arc in
the `spirits` brief's palette, with a coolant-spray or sparks **blur-through** at the mill.

Note the constraint that comes with the subject: **invent the issuer.** Build in that
visual register, never reproduce a real card network's name, wordmark or trade dress, and
don't present it as a real financial product with real terms.
